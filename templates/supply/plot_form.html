Where is it?

Choose one way to show the area. Most suppliers draw it on the map. If the producer gave you a file (GeoJSON), upload it instead. For small plots (4 hectares or less) a single point can be enough; larger plots need the outline.

Draw on the map

Use the pentagon tool on the map to click around the edge of the area, then click the first point to finish. Use the edit tool to move corners, or the bin to remove a shape. You can draw several separate areas.

Upload a GeoJSON file

A GeoJSON file ends in .geojson or .json. Producers, forestry agencies and mapping apps can usually export one.
